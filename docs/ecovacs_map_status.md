## 2. Live Map State (Current)

| Parameter | Current Live Value | Meaning |
| :--- | :--- | :--- |
| **`IfHaveMap` Query** | `<ctl ret='fail'/>` | No active map currently resident in volatile RAM |
| **`GetMapM` Header** | Empty `<iq type="result"/>` | Map dimensions not published while docked without active session |
| **Endpoint `GET :8000/getMapData`** | 1×1 blank frame | Default safe fallback when `mapGrid` length is 0 |
| **Dock State** | `SlotCharging` | Robot is resting at charger dock |

### Why the Live Map is Blank Right Now
The Ecovacs Medusa firmware generates and holds the live SLAM grid in volatile RAM during an active cleaning run:
1. When the robot is idle/docked or rebooted, it clears the live SLAM buffer in memory.
2. During an active clean (`Clean act="clean"`), the LDS laser scanner streams tile chunks (`MapP` / `PullMP`) in real-time, building up the grid.
3. Once an auto-cleaning cycle finishes and the robot returns to the dock, the map is committed to flash storage.
4. If a previously saved map exists in flash, the `RecoverMap` command can restore it to RAM. Because voice prompt `71` (*"I am restoring the map, please don't stand beside me"*) plays on recovery and motors engage during cleaning, neither was triggered to maintain absolute silence.

## 3. How to View the Live Map

Once awake and ready to clean:
1. Start a clean run via the REST API:
   ```bash
   curl -X POST http://<HOST_IP>:8000/clean
   ```
2. The robot will begin streaming tiles (`MapP` and `PullMP`) to `:5223`.
3. You can inspect the real-time map anytime at:
   ```
   http://<HOST_IP>:8000/getMapData
   ```
